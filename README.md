# Sinova — maquette site web (Webminds Digital Solutions)

Maquette statique, sans dépendance : `index.html` (accueil) et `produit.html` (page produit, climatiseur).

## Déployer
- Vercel : importer le repo, framework "Other", pas de build, output = racine.
- Pour tester en local : ouvrir `index.html` dans le navigateur.

Les zones marquées « à intégrer » (vidéo, photos usine, visuels produits) et les valeurs entre [crochets] sont à remplacer.
